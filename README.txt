CUSTOMER SALES & ACTIVITY MANAGER — GOOGLE SHEETS VERSION 6

1. Read SETUP_GOOGLE_SHEETS.md.
2. Add your Google OAuth Web Client ID to google-config.js.
3. Host this entire folder on an HTTPS website or localhost.
4. Open the app and click Connect Google.
5. Click Create Google Sheet for first-time setup.

The Google Sheet becomes the live shared master record and is refreshed automatically after each saved change.
A local browser copy is retained as a safety backup.
